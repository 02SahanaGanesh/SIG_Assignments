Project Name : F1 2026 Season Tracker

Reference Website

Formula 1 official website:
https://www.formula1.com/

The website was used as a general reference for the Formula 1 theme, driver information and overall layout inspiration.

What I Built

I built a Formula 1 themed website that presents an overview of the 2026 season.

The website includes:
- A hero section with an F1 car background
- A season overview
- All 22 drivers with their images, numbers and teams
- A drama and controversies section
- Navigation links
- Hover effects
- Responsive design for different screen sizes

Technologies Used
- HTML5
- CSS3

What I Learned

Through this project, I learned how to:
- Structure a webpage using HTML
- Connect HTML with an external CSS file
- Use CSS Grid to create card layouts
- Add and style images
- Create navigation links
- Use hover effects and transitions
- Make a website responsive using media queries
- Organize files into folders

 Challenges

One of the main challenges was creating a consistent layout for all 22 driver cards.

I also had to make sure the driver images were displayed properly and that the website remained responsive on smaller screens.

AI Usage

AI was used as a learning and development aid during this project.
I used AI to:
- Understand HTML and CSS concepts
- Get suggestions for page structure and styling
- Help with responsive CSS
- Debug minor HTML/CSS issues
- Improve the visual design of the website
The final website was reviewed and edited by me to match the project requirements and my design choices.
